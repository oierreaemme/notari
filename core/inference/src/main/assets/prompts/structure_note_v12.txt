Rules:
- Transform ONLY what is in the transcript. Never invent facts, names, dates, places, events.
- Remove fillers/repetitions; preserve meaning. Keep the user's meta-speech ("non ricordo", "aspetta") verbatim — it IS content.
- Fix obvious typos, broken dictation segmentation, and missing punctuation. If meaning is unclear keep the fragment verbatim. Never alter proper nouns.
- Detect the language; write title, tags, body_markdown and surface_form in THAT language. Do not translate. Never borrow the examples' language.
- The title field IS the heading: body_markdown must NOT start with `# Title`.
- COMMITMENTS ("devo", "devo ricordarmi", "I need to", "I must", "non dimenticare di", "hay que", "je dois", "ich muss", "preciso de") → `- [ ]` checkbox. ALWAYS, one per commitment, scanning the WHOLE transcript. EVENTS and FACTS ("riunione alle 10", "domani c'è il deploy") → prose, never checkbox. Spoken ENUMERATIONS ("pane, latte, mele") → `- ` bullets, never comma prose.
- Genuine topic switches ("due cose", "primo... secondo", "another thing") → one `##` per topic; the event/context prose comes FIRST under each heading, then its checkboxes. Otherwise natural paragraphs; do not bullet a single sentence.
- mentions[] = datetime references ONLY — never people, places or projects (key entities go **bold** in the body, sparingly). surface_form = the SHORTEST span naming the time, with its natural preposition ("alle 14"). Resolve against CURRENT TIMESTAMP: ISO-8601 with offset, date-only when no time stated, null only when genuinely vague ("una di queste sere"). No time reference in the note → empty array; never emit "null"/placeholder entries.
- tags: ALWAYS 2-4 broad categories (lavoro, personale, idea, riflessione, salute / work, personal, idea, health), lowercase-kebab, in the note's OWN language. REUSE an EXISTING TAG verbatim when it fits the topic AND matches the note's language; never coin a synonym of one, never reuse one in a different language.
